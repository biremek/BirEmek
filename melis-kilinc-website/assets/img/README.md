# Görseller

Bu klasöre aşağıdaki dosyaları eklediğinizde site otomatik olarak fotoğrafları gösterir.
Dosya yoksa site bozulmaz; yerine şık bir yer tutucu görünür.

| Dosya adı  | Nerede görünür            | Önerilen ölçü / oran      |
|------------|---------------------------|---------------------------|
| `melis.jpg`| Ana bölümdeki yuvarlak portre | 800×800 px (1:1, kare)  |
| `salon.jpg`| "Hakkımızda" bölümü        | 900×1125 px (4:5, dikey)  |
| `g1.jpg`   | Galeri – Kaş Alımı         | 800×1000 px (4:5)         |
| `g2.jpg`   | Galeri – Microblading      | 800×1000 px (4:5)         |
| `g3.jpg`   | Galeri – Protez Tırnak     | 800×1000 px (4:5)         |
| `g4.jpg`   | Galeri – Cilt Bakımı       | 800×1000 px (4:5)         |
| `g5.jpg`   | Galeri – Manikür           | 800×1000 px (4:5)         |
| `g6.jpg`   | Galeri – Nail Art          | 800×1000 px (4:5)         |

## İpuçları

- Instagram'daki mevcut paylaşımlarınızı indirip bu isimlerle kaydetmeniz yeterlidir.
- Fotoğrafları web için sıkıştırmanız (her biri 300 KB altı) sayfanın hızlı açılmasını sağlar.
- `.jpg` yerine `.webp` kullanmak isterseniz `index.html` içindeki dosya uzantılarını da güncelleyin.
- Galeri başlıklarını değiştirmek için `index.html` içindeki `<figcaption>` metinlerini düzenleyin.
